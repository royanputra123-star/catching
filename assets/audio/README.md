# Background music goes here 🎵

Drop **one** music file in this folder to give the game a soundtrack (for example
`Rush E_1.mp3`). The game loops it while a round is running.

## Accepted file names / places

The game looks for these in order and plays the first one it finds:

| Where | File name |
| --- | --- |
| project root (next to `index.html`) | `Rush E_1.mp3` |
| `assets/audio/` | `Rush E_1.mp3` |
| `assets/audio/` | `rush-e.mp3` |
| `assets/audio/` | `background-music.mp3` |
| `assets/audio/` | `background-music.ogg` |
| `assets/music/` | `Rush E_1.mp3` |

You do **not** need to edit any code. Rename your file to one of the names above
(or put it in the project root as `Rush E_1.mp3`) and reload the page.

If no file is found the game still works: catch and miss sounds are generated by the
browser, and the browser console prints a friendly reminder.

## Tips

- Keep the file small (2–5 MB) so a classroom page loads fast.
- Any browser-playable format works: `.mp3`, `.m4a`, `.ogg`, `.wav`.
- Use the **SOUND ON** button in the top bar to mute everything, music included.
